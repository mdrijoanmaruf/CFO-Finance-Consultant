## 🌐 Overview

This is the official professional portfolio and consulting platform for **MD. Al Amin Bhuiyan**, a highly accomplished CFO and Corporate Finance Consultant with 22+ years of experience in Bangladesh.

The platform is designed to showcase professional achievements, outline consulting services (Fractional CFO, Corporate Governance, Treasury, etc.), publish industry insights, and provide a secure contact portal for lead generation.

### ✨ Key Features

- **Premium Design Aesthetic:** Deep dark mode (`#060e1c`) intertwined with elegant gold gradients (`#c8a96e`) and glassmorphism UI elements to project authority and luxury.
- **Dynamic Insights (Blog):** A built-in, statically generated Markdown-style article system for publishing financial insights.
- **Enterprise-Grade SEO:** 
  - Dynamic `sitemap.xml` and `robots.txt`.
  - Comprehensive Open Graph & Twitter Card metadata.
  - Advanced JSON-LD Structured Data (`Person`, `ProfessionalService`, `Article`) implementation for rich Google search results.
- **Responsive Architecture:** Fluid typography and grid systems that look stunning on mobile, tablet, and desktop displays.
- **Lead Generation:** A fully integrated contact and consultation request form.

## 🚀 Getting Started

First, clone the repository and install the dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📈 SEO & Performance Configuration

This project is highly optimized for search engines:
- The base URL is configured to `https://al-amin-pi.vercel.app/` across `app/layout.tsx`, `sitemap.ts`, and `robots.ts`.
- When deploying to a new custom domain, ensure you update the `BASE_URL` in those respective files to maintain SEO integrity.
